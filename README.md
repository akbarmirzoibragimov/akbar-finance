# Akbar Finance 3.0

Личное приложение для учёта финансов: счета, кредиты, плановые платежи, бюджеты, цели, переводы родителям, статистика и прогнозы. Интерфейс сделан по образцу Wallet by BudgetBakers (тёмная тема в стиле iOS, плитки счетов, нижняя панель вкладок, кнопка «+»), но код полностью свой, без чужих логотипов и ресурсов.

**Работает полностью локально.** Нет серверов, аккаунтов, облачной синхронизации и подключения к банкам. Данные хранятся только в браузере на устройстве (IndexedDB).

## Состав архива

| Файл / папка | Что это |
|---|---|
| `akbar-finance-standalone.html` | Всё приложение в одном файле. Можно просто открыть в браузере. |
| `index.html`, `src/`, `icons/`, `manifest.webmanifest`, `service-worker.js` | Версия PWA (устанавливаемое приложение, работает офлайн), если открыть через http(s). |
| `tools/build.js` | Пересборка автономного файла из `src/` (`node tools/build.js`). |
| `README.md` | Эта инструкция. |

**Вашей личной книги (`akbar-ledger-2026-11-25.json`) в архиве нет.** Это отдельный файл, его нужно хранить у себя и импортировать в приложение. В исходном коде приложения ваших финансовых данных нет: при первом запуске открывается пустой экран с кнопками «Импортировать файл книги» и «Начать новую книгу».

## Первый запуск и импорт личной книги

1. Откройте приложение (см. ниже для Windows и iPhone).
2. Нажмите **«Импортировать файл книги»** и выберите `akbar-ledger-2026-11-25.json`.
3. Приложение проверит файл и покажет, что в нём: счета, записи, плановые платежи, предупреждения. Если файл повреждён или не подходит, импорт не выполняется.
4. Нажмите «Загрузить книгу». Если в приложении уже есть данные, можно выбрать:
   - **Заменить**: нужно поставить галочку подтверждения. Перед заменой текущая книга сохраняется в снимок.
   - **Объединить**: добавляется только новое, дубли записей пропускаются.

## Windows

**Вариант 1. Самый простой.** Дважды щёлкните `akbar-finance-standalone.html`. Файл откроется в Chrome или Edge. Данные сохраняются в браузере для этого файла. Если файл переместить, переименовать или открыть в другом браузере, это будет другое хранилище. Тогда используйте экспорт и импорт JSON.

**Вариант 2. Установка как приложение (PWA) с офлайн-режимом.** Распакуйте архив в папку, откройте в ней командную строку и выполните:

```
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в Edge или Chrome и выберите меню → «Установить приложение». Python можно поставить из Microsoft Store, регистрация не нужна.

## iPhone: честно об ограничениях

- iPhone не умеет нормально запускать локальный HTML-файл из приложения «Файлы». Предпросмотр не выполняет JavaScript, поэтому приложение там не заработает.
- Офлайн-режим (service worker) и полноценная установка на экран «Домой» работают только по **https** или с `localhost`.
- Safari может удалить данные сайта, если им долго не пользоваться. Данные веб-приложения, добавленного на экран «Домой», хранятся отдельно от вкладки Safari.
- Поэтому **регулярно делайте резервную копию**: Ещё → Данные → «Резервная копия JSON». Сохраняйте её в «Файлы» или iCloud Drive.

Варианты без регистрации на сторонних сервисах:

1. **Через компьютер в той же Wi-Fi-сети.** На Windows запустите `python -m http.server 8000 --bind 0.0.0.0`. На iPhone откройте в Safari `http://<IP-компьютера>:8000`, например `http://192.168.1.10:8000`, импортируйте книгу и при желании выберите «Поделиться» → «На экран Домой». Ограничения: это http, поэтому офлайн-кэша нет и компьютер должен быть включён при открытии. Если IP компьютера изменится, это будет «другой сайт» с пустыми данными, и книгу придётся импортировать из резервной копии.
2. **Приложение — локальный веб-сервер на самом iPhone.** В App Store есть приложения, которые раздают папку по адресу `http://localhost:…`. Положите туда файлы из архива. Адрес `localhost` считается безопасным, поэтому могут заработать офлайн-режим и установка. Конкретное приложение я не проверял, выбирайте на своё усмотрение.
3. **Свой https-хостинг** (например, GitHub Pages) даёт полноценную PWA на iPhone. Но для этого нужен аккаунт, поэтому только с вашего решения. Публиковать можно **только файлы приложения**, без файла личной книги. Книга импортируется на телефоне вручную.

## Перенос данных между iPhone и Windows

Облачной синхронизации нет. Для переноса: на одном устройстве откройте Ещё → Данные → «Резервная копия JSON», передайте файл (AirDrop, iCloud Drive, кабель), на другом устройстве выполните «Импорт» → «Заменить» или «Объединить».

## Резервные копии и восстановление

- Снимок книги создаётся автоматически раз в день при открытии и перед каждой заменой. Хранятся последние 15. Восстановить снимок: Ещё → Данные.
- Любую операцию можно отменить кнопкой «Отменить» во всплывающем сообщении. Записи можно аннулировать: остатки счетов при этом пересчитываются.
- Все изменения пишутся в «Журнал изменений».

## Что умеет

- Счета: наличные, текущие, накопительные, резерв, кредитные карты (лимит, доступно, превышение, минимальный платёж), займы и рассрочки.
- Записи: расход, доход, перевод, покупка картой, получение кредита, погашение с разделением на основной долг и проценты, проценты, комиссии, перевод родителям, корректировка.
- Плановые платежи и доходы: подтверждение оплаты без двойного списания, частичная оплата, пропуск, серии платежей, календарь.
- Бюджеты по категориям, план доходов (доход конца месяца финансирует следующий месяц), бюджетные периоды, дефицит и альтернативы.
- Debt Freedom: структура долга, стратегии snowball/avalanche/своя, прогноз закрытия.
- Сценарий повторного займа (вкл./выкл., не создаёт фактических операций).
- Цели, Family Support, финансовое здоровье (9 прозрачных факторов), проверка «Могу ли я себе это позволить?», сценарный симулятор.
- Статистика: Balance, Spending, Cash Flow, Outlook, Credit, Income. Фактические данные показаны сплошной линией, плановые — пунктиром.
- Помощник на правилах (это **не ИИ**), уведомления внутри приложения (push-уведомлений нет), итоги месяца.
- Мультивалютность: курсы вводятся вручную. Русский и английский, тёмная и светлая темы.
- Экспорт JSON и CSV, импорт с проверкой и защитой от дублей.

## Ограничения

- Нет облака, аккаунтов, синхронизации, подключения к банкам, push-уведомлений и ИИ.
- Курсы валют и цены активов вводятся вручную.
- Неподтверждённые ставки по кредитам не используются для начисления процентов. Расчётные ставки помечены как оценка.
